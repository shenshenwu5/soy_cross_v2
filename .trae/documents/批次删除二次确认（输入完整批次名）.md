## 目标
- 在“批次管理”中删除选中批次前，要求用户输入完整的批次名称；仅当输入与选中批次完全一致时才允许删除。

## 修改范围
- 文件：
  - R/mod_cross_app.R：批次管理的删除弹窗与确认逻辑
  - apps/run_cross_app.R：应用批次管理的删除弹窗与确认逻辑

## UI 改造
- 在删除弹窗中加入一个文本输入框：textInput(ns("confirm_delete_text"), "请输入批次名称以确认删除")。
- 弹窗正文显示待删除批次名，强调必须输入与该批次名称一致的文本。

## 服务器端校验
- 在 observeEvent(input$confirm_delete_batch) 中：
  - 获取当前选中行的批次名 batch_name。
  - 读取输入框值 typed <- trimws(input$confirm_delete_text)。
  - 若 typed 与 batch_name 不一致：
    - showNotification("输入的批次名称不匹配，未执行删除", type = "error")；
    - 保持弹窗不关闭，让用户重新输入。
  - 一致时：
    - removeModal()；执行 DELETE FROM crosses WHERE batch = ? 并刷新列表。

## 行为细节
- 匹配为“完全一致（区分大小写）”，但忽略前后空格（trim）。
- 不引入 shinyjs；通过点击确认时的校验实现禁删。

## 验证
- 手动验证：
  - 输入错误名称：不删除且提示错误。
  - 输入正确名称：成功删除并刷新批次列表。

## 不影响项
- 保持现有删除 SQL 与列表刷新逻辑不变；仅增加确认输入。
